Baseline: branch `v5-homepage-drafts` @ 8b6a9e9. Rule agreed: **the live site is right** where values differ.
Site accessibility problems are listed in section 6 and are not silently changed.

## 3. Tokens: where they live

Real sources: `src/styles/globals.css` (`@theme` + `.satr-*` classes), `public/css/type-scale.css` (generated by
`scripts/build-type-scale.py`), `src/styles/fonts.css`. `tailwind.config.ts` is dead (Tailwind v4 ignores it).
`public/handoff/tokens.css` was hand-written and drifted.

Colours: black #000, white #fff, muted #4d4d4d, blue #b5c6cd, yellow #f0eebe, green #37b066, disabled #c8c8c8,
line-muted rgba(0,0,0,.25), link #fdbe0d (deprecated in hand-off).
**No token yet:** #333 (hover), #e8e8e8, #ececec, #6b6b6b, #b00020 (error red), #c62828 (second red, Profile),
#238636, #717171, #4a5459 (used as arbitrary class). ~30 hex literals outside `@theme`; ~295 arbitrary px/rem classes
(Cabinet/Profile 42, HomeHeroV4Final 23, SiteHeader 11, OnboardingWizard 11, Footer 7).

Fonts: Noto Serif 400 and IBM Plex Mono 300/400/500 from Google Fonts at runtime (not self-hosted).
e-Ukraine: 300 and 400 both point to the same Light file, 700 is Bold. Usage: 149 `font-mono`, 57 `font-ukraine`, 49 `font-serif`.

## 4. Rem-base mismatch (important)
`html { font-size: 18px }` in globals.css, but `type-scale.css` is generated for 1rem = 16px. Measured on the dev server
at 1015px wide: `--step-md` = 19.31px (design 17.41px), `--step-h1` = 58.3px. Up to ≈ +12% on every fluid step,
and h1 reaches ≈81px instead of 72px at ≥1440. `type-scale-static.css` (ROOT=18) is correct for the static pages, so
the React app and the static pages render the same step at different sizes.
Decision needed before stage 2 changes any size (see plan: before/after for approval).

## 5. Radii, shadows, focus, z-index
No spacing/radius/shadow tokens in `src/`. Squircle radius passed in code: 16 (Button, Tag, Select), 12 (avatar),
10 (wizard), 22/24 (notifications). Focus ring: `outline-2` with offset 2 (×12) or 4 (×3). Z-index raw: 10–80, [60], [70], [80].
Only shadow: `shadow-[0_2px_0_0_#000]` in FieldSelect.

## 6. Accessibility issues of the live site (reported, not changed)
- Button 47px, tag 44px: OK. Pagination current 32px circle: below 44px target.
- #4a5459 text on #b5c6cd: 4.4:1, fails AA.
- Placeholder #6b6b6b on white: 5.3:1 OK; `opacity-50` current breadcrumb: ≈ 3.9:1 on white, fails AA.
- Focus ring inconsistent (offset 2 vs 4), no ring on cards.
- Google Fonts loaded at runtime (privacy).

## 7. Squircle machinery
React: `useSquircleClipPath.ts` + `squirclePath.ts` (Figma corner smoothing 0.9) + `SquircleDefs.tsx`.
Static pages: `public/js/satr-squircle.js` (vanilla port) + `public/css/satr-squircle.css`.
Stage 4: the hand-off's native `corner-shape` file is gone; `public/js/satr-shape.js` draws the same path as React (checked equal for a ring button, a filled button and a tag).

## 8. Existing machinery to reuse
`scripts/build-chrome.mjs` and `build-auth.mjs` render React components to static HTML (`renderToStaticMarkup`)
into marker blocks; `build-chrome-css.mjs` builds a scoped Tailwind subset `public/css/satr-chrome.css`.
Stage 5 follows the same pattern for `states.html`.

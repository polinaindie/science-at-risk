Squircle

The squircle is part of the identity. It is not border-radius: each corner is one bezier with Figma corner smoothing 0.9. ../js/satr-shape.js draws it (no dependencies) and gives the same path as the React site, character for character. Without JavaScript the element keeps its CSS border-radius (a plain rounded rectangle).

Markup contract

<!-- filled shape: tags, chips -->
<a class="satr-tag" data-squircle href="…"><span>Biology</span></a>

<!-- shape on a background layer: buttons (the ring must not clip the label) -->
<button class="satr-squircle satr-squircle--bordered" data-squircle="bg" data-ring="2">
  <span class="satr-squircle__bg" aria-hidden="true"></span>Download
</button>

<script src="/js/satr-shape.js" defer></script>

data-radius in px (default 16). data-ring in px draws a hollow outline that fills on hover. Elements added later (for example by the search results): window.satrShape.init(container).
